# 사주팔자 계산기 v2

기존 `artofstock/saju` PWA를 기반으로 확장한 버전입니다.

## 주요 개선
- 기존 양력/음력 및 윤달 입력 유지
- 자시 처리 방식 유지
- 사주 원국(년·월·일·시) 표시
- 오행 분포 개선
- 십성 배치
- 지장간 표시
- 12운성 표시
- 천간합·삼합·반합·육합
- 충·형·파·해 관계 표시
- 월령과 통근을 반영한 간이 신강/신약 점수
- 용신·희신 후보를 설명과 함께 표시
- 대운·세운·월운·일운
- PWA 캐시 버전 갱신

## 주의
신강/신약 및 용신·희신은 명리학의 여러 판단법을 하나의 계산 규칙으로 단순화한 참고값입니다.
학파별 차이가 있으므로 전문 만세력의 단일 정답으로 취급하지 않습니다.

## 실행
`index.html`을 정적 웹서버 또는 GitHub Pages에 올려 사용할 수 있습니다.

## v2.1 수정 사항
- **치명적 버그 수정**: `운세 흐름`(대운·세운·월운·일운) 렌더링에서 쓰던 `flow` 객체가 선언되어 있지 않아, "사주 보기" 버튼을 눌러도 strict mode에서 즉시 오류가 나며 결과 화면이 아예 뜨지 않던 문제를 고쳤습니다.
- 음력 생년월일 입력을 `<input type=date>` + 윤달 체크박스 방식에서 연/월/일 select로 바꿔, 실제 존재하지 않는 음력 날짜(예: 그 달에 없는 30일, 윤달이 없는 달의 "윤달")를 애초에 고를 수 없도록 했습니다.
- 날짜 계산 실패 시 `alert()` 대신 폼 안의 인라인 오류 메시지로 표시하도록 변경했습니다.
- 고령자의 경우 현재 대운이 대운 표/선택창의 앞 10개 안에 없어 표시가 안 되던 경우를 대비해 현재 대운이 항상 포함되도록 보강했습니다.
- 모바일 카드 스와이프용으로 만들어졌지만 이후 코드에 의해 항상 무시되던 죽은 CSS 규칙을 정리했습니다.
- 이름을 비워두면 "이 님의 사주"로 어색하게 표시되던 것을 "사주 결과"로 수정했습니다.
- 카드 그림자, 버튼/입력창 포커스 표시, 세그먼트 버튼 hover·`aria-pressed`, 십성 색상 범례 등 시각적 다듬기와 접근성을 보완했습니다.
- 서비스워커 캐시 버전을 올려 기존 사용자도 업데이트된 파일을 받도록 했습니다.
